uHandbit · micro:bit V2 · getting started

Seating the micro:bit, moving a finger, waving the hand

The micro:bit is the brain of your robotic hand. Part 1 shows how to plug it into the expansion board. Part 2 takes you from power-on to one finger bending when you press a button. Part 3 builds the waving-hand program on your Mac and loads it onto the micro:bit. Part 4 makes a fist and opens the hand. Part 5 counts from 0 to 5 on the fingers. Part 6 plays rock, paper, scissors. Part 7 closes and opens the hand when you clap. Part 8 connects the glowing ultrasonic sensor. Part 9 controls the hand from your phone through an ESP32. Parts 10 and 11 are research notes for driving the servos from the ESP32 without the micro:bit (not tested yet).

LEDs and buttons face out

The side with the 5×5 LED grid and the A and B buttons faces the same way as the board's chips and printed labels.

Gold pins go in the slot

The gold strip marked 0 1 2 3V GND goes down into the black connector.

USB port ends up on top

The small Micro-USB port is on the edge opposite the pins, so you can still plug in your Mac's cable once it's seated.

Part 1: Plug in the micro:bit

  1. Switch the power off.Slide the power switch (8 in the board photo below) to off. Never push the micro:bit in or pull it out while the power is on.
  2. Hold the micro:bit by its sides.LED grid and A/B buttons facing you, the gold pins pointing down. Try not to touch the gold pins.
  3. Line it up with the black slot.That's the long black connector (3 in the board photo). Centre the micro:bit over it so it's square, not tilted.
  4. Press straight down, firmly.It's a tight fit, so steady pressure is normal. Stop when the gold strip has gone into the slot and the micro:bit doesn't move any further. Don't rock it side to side hard.
  5. Check it's seated.It should stand straight and not wobble or lift out when you tug gently.
  6. Go on to Part 2.Leave the power off for now. Part 2 below covers power, USB and your first program.

Right way, wrong way

Correct

  • LED grid and A/B buttons face the same way as the board's chips and labels
  • Gold pins hidden in the slot, not visible above it
  • Micro-USB port on the top edge, easy to reach
  • Power on shows lights on the board and the micro:bit

Take it out and redo

  • You can see the micro:bit's back (the chips and "V2" print) facing out
  • It's tilted, or part of the gold strip is still showing
  • It rocks or pops out easily
  • Nothing lights up, or the servos twitch strangely: power off first, then reseat
Part 2

Power up and connect to your Mac

The servos need the barrel-connector adapter

The USB cable only powers the micro:bit. The finger and wrist motors get power only from the 6V adapter plugged into the round DC jack, with the power switch on. With USB alone you'll see the smiley, but nothing will move.

  1. Check the servo cables.The hand's servo cables are plugged into the servo ports 1–6. The power switch is still off.
  2. Plug in the 6V adapter. This is required.Into the board's round DC jack (9), and the adapter into the wall. Keep it plugged in whenever you want the hand to move.
  3. Switch the power on.You should see lights on the board. The micro:bit may run its built-in demo, and the hand may twitch once. Both are normal, but keep your fingers clear.
  4. Connect the USB cable.Use a USB-C to Micro-USB data cable from your MacBook to the port on the top edge of the micro:bit. You should see a drive called MICROBIT in Finder's sidebar under Locations.

Set up MakeCode

  1. Open MakeCode in Chrome.Go to makecode.microbit.org, click New Project and name it hand-test.
  2. Add the StartbitV2 extension.Click the gear icon, then Extensions. Paste https://github.com/Hiwonder/StartbitV2 into the search box and click the result.
  3. Confirm it loaded.You should see a blue StartbitV2 category in the block list.

  1. Click Download.It's at the bottom left. When MakeCode offers to Connect device, follow the prompts and pick your micro:bit.
  2. If connecting doesn't work, drag the file instead.A hand-test.hex file lands in Downloads. Drag it onto the MICROBIT drive. The yellow light on the back of the micro:bit flashes while it copies.

Test it

  1. Look at the LED grid.You should see a smiley face.
  2. Press A.One finger bends slowly over one second.
  3. Press B.The finger straightens again.
What happensWhat to do
No MICROBIT drive appearsYour cable may be charge-only. Try a different cable.
Red squiggly lines in the codeThe extension didn't load. Add StartbitV2 again from the gear menu.
Smiley shows, but no finger movesThe barrel-connector adapter isn't powering the board. Plug the 6V adapter into the round DC jack and check the switch is on. USB alone can't drive the motors. To check, unplug USB: if the smiley still appears, the board has power.

A different finger movesThat's fine. The servo numbers are just wired differently.
A servo buzzes, strains or gets hotSwitch the power off right away and note which servo it was.

The program

This is waving-hand/main.ts. It's the community waving-hand project converted to the StartbitV2 extension. The fingers hold still and servo 1 (the wrist) swings between 0° and 180°.

// uHandbit waving hand (micro:bit V2 + StartbitV2 extension)
// Based on https://github.com/cloverdale-robotics-learning/waving-hand
// Button A: start waving. Button B: stop.
// The servos only move with the 6V adapter plugged into the barrel jack.

let waving = false

StartbitV2.startbit_Init()

// Hold the thumb (servo 2) and fingers (servos 3-6) in place
StartbitV2.setPwmServo(StartbitV2.startbit_servorange.range1, 2, 0, 500)
StartbitV2.setPwmServo(StartbitV2.startbit_servorange.range1, 3, 130, 500)
StartbitV2.setPwmServo(StartbitV2.startbit_servorange.range1, 4, 130, 500)
StartbitV2.setPwmServo(StartbitV2.startbit_servorange.range1, 5, 130, 500)
StartbitV2.setPwmServo(StartbitV2.startbit_servorange.range1, 6, 130, 500)
basic.showIcon(IconNames.Happy)

input.onButtonPressed(Button.A, function () {
    waving = true
    basic.showArrow(ArrowNames.East)
})

input.onButtonPressed(Button.B, function () {
    waving = false
    basic.showIcon(IconNames.Happy)
})

// Swing the wrist (servo 1) back and forth while waving is on
basic.forever(function () {
    if (waving) {
        StartbitV2.setPwmServo(StartbitV2.startbit_servorange.range1, 1, 0, 500)
        basic.pause(1000)
        StartbitV2.setPwmServo(StartbitV2.startbit_servorange.range1, 1, 180, 500)
        basic.pause(1000)
    } else {
        basic.pause(100)
    }
})

Build and load it

  1. Open Terminal and go to the project.Paste the first line of the commands below and press Return.
  2. Build it.The second line compiles the program. The first build downloads the MakeCode toolchain and the StartbitV2 extension, so give it a few minutes. You should see Build OK, and a new file built/binary.hex.
  3. Copy it onto the micro:bit.The third line copies the file to the MICROBIT drive. The -X skips macOS's hidden metadata files, which the micro:bit doesn't need.
  4. Wait for the restart.The yellow light on the back flashes, the drive disappears, and then it comes back. A successful load leaves only DETAILS.TXT and MICROBIT.HTM on the drive. If FAIL.TXT appears, open it to read the error and copy the file again.

Wave

  2. Press A.An arrow appears and the wrist swings back and forth once a second. Keep your hands clear.
  3. Press B.The smiley comes back and the wrist stops at the end of its current swing.

Part 4

Fist and open hand

Press A and the hand closes into a fist. Press B and it opens. When closing, the fingers fold first and the thumb wraps over them. When opening, the thumb moves out of the way first so it doesn't catch. The wrist doesn't move.

PartFistOpen
Fingers (servos 3–6)0130
Thumb (servo 2)1400

Confirmed on your hand: A makes a fist and B opens it with these angles. If you ever rebuild the hand and the directions flip, swap the numbers in the four lines at the top of main.ts, then build and copy again.

The program

This is fist-open/main.ts. The four named numbers at the top control every position, so you only change them in one place.

// uHandbit fist and open hand (micro:bit V2 + StartbitV2 extension)
// Button A: make a fist. Button B: open the hand.
// Positions from the community uHandbit projects:
//   fingers (servos 3-6): 0 = closed, 130 = open
//   thumb (servo 2):    140 = closed,   0 = open
// The servos only move with the 6V adapter plugged into the barrel jack.

const FINGER_CLOSED = 0
const FINGER_OPEN = 130
const THUMB_CLOSED = 140
const THUMB_OPEN = 0
const MOVE_MS = 500

function moveFingers(angle: number) {
    for (let servo = 3; servo <= 6; servo++) {
        StartbitV2.setPwmServo(StartbitV2.startbit_servorange.range1, servo, angle, MOVE_MS)
    }
}

function moveThumb(angle: number) {
    StartbitV2.setPwmServo(StartbitV2.startbit_servorange.range1, 2, angle, MOVE_MS)
}

// Fist: fold the fingers first, then wrap the thumb over them
function makeFist() {
    basic.showIcon(IconNames.SmallSquare)
    moveFingers(FINGER_CLOSED)
    basic.pause(MOVE_MS + 200)
    moveThumb(THUMB_CLOSED)
}

// Open: move the thumb out of the way first, then straighten the fingers
function openHand() {
    basic.showIcon(IconNames.Square)
    moveThumb(THUMB_OPEN)
    basic.pause(MOVE_MS + 200)
    moveFingers(FINGER_OPEN)
}

StartbitV2.startbit_Init()
openHand()

input.onButtonPressed(Button.A, function () {
    makeFist()
})

input.onButtonPressed(Button.B, function () {
    openHand()
})

Part 5

Counting on fingers

The hand starts as a fist with 0 on the LED grid. Press A to raise one more finger and B to lower the last one raised. The display always shows how many fingers are up.

CountFinger raisedServo
1Index3
2Middle4
3Ring5
4Little6
5Thumb2

New idea in this program: lists. SERVOS, OPEN and CLOSED hold one entry per finger in counting order. The count picks the entry, so position 0 is the index finger, servo 3, open at 130 and closed at 0. To count in a different order, change the order in all three lists the same way.

The program

This is finger-counting/main.ts.

// uHandbit finger counting (micro:bit V2 + StartbitV2 extension)
// Starts as a fist showing 0.
// Button A: raise one more finger (count up to 5).
// Button B: lower the last finger raised (count down to 0).
// Angles confirmed on this hand:
//   fingers (servos 3-6): 0 = closed, 130 = open
//   thumb (servo 2):    140 = closed,   0 = open
// The servos only move with the 6V adapter plugged into the barrel jack.

const MOVE_MS = 400

// Counting order: index, middle, ring, little finger, then thumb
const SERVOS = [3, 4, 5, 6, 2]
const OPEN = [130, 130, 130, 130, 0]
const CLOSED = [0, 0, 0, 0, 140]

let count = 0

function setFinger(position: number, open: boolean) {
    const angle = open ? OPEN[position] : CLOSED[position]
    StartbitV2.setPwmServo(StartbitV2.startbit_servorange.range1, SERVOS[position], angle, MOVE_MS)
}

// Start as a fist: fingers first, then the thumb over them
StartbitV2.startbit_Init()
for (let i = 0; i < 4; i++) {
    setFinger(i, false)
}
basic.pause(MOVE_MS + 200)
setFinger(4, false)
basic.showNumber(count)

input.onButtonPressed(Button.A, function () {
    if (count < 5) {
        setFinger(count, true)
        count += 1
        basic.showNumber(count)
    } else {
        // Already showing 5
        basic.showIcon(IconNames.No)
        basic.pause(500)
        basic.showNumber(count)
    }
})

input.onButtonPressed(Button.B, function () {
    if (count > 0) {
        count -= 1
        setFinger(count, false)
        basic.showNumber(count)
    } else {
        // Already a fist
        basic.showIcon(IconNames.No)
        basic.pause(500)
        basic.showNumber(count)
    }
})

Part 6

Rock, paper, scissors

Press A. The hand closes into a fist and the display counts down 3, 2, 1. Then the hand shows a random pick, and you play yours at the same moment. Press A again for another round.

PickHandLED grid
RockStays a fistSmall square
PaperThumb opens, then all four fingersBig square
ScissorsIndex and middle fingers up, the rest downScissors icon

New ideas in this program: random numbers and a lock. randint(0, 2) picks 0, 1 or 2 at random, and the if / else if / else turns that number into a gesture. The playing flag ignores extra presses of A until the round is over, so the hand doesn't get two sets of moves at once. The micro:bit sits on the hand, so a button works better than shaking to start a round.

The program

This is rock-paper-scissors/main.ts.

// uHandbit rock, paper, scissors (micro:bit V2 + StartbitV2 extension)
// Button A: count down 3, 2, 1, then show a random rock, paper or scissors.
// Angles confirmed on this hand:
//   fingers (servos 3-6): 0 = closed, 130 = open
//   thumb (servo 2):    140 = closed,   0 = open
// The servos only move with the 6V adapter plugged into the barrel jack.

const FINGER_CLOSED = 0
const FINGER_OPEN = 130
const THUMB_CLOSED = 140
const THUMB_OPEN = 0
const MOVE_MS = 400

const THUMB = 2
const INDEX = 3
const MIDDLE = 4
const RING = 5
const LITTLE = 6

let playing = false

function move(servo: number, angle: number) {
    StartbitV2.setPwmServo(StartbitV2.startbit_servorange.range1, servo, angle, MOVE_MS)
}

// Fist: fingers first, then the thumb over them
function rock() {
    move(INDEX, FINGER_CLOSED)
    move(MIDDLE, FINGER_CLOSED)
    move(RING, FINGER_CLOSED)
    move(LITTLE, FINGER_CLOSED)
    basic.pause(MOVE_MS + 200)
    move(THUMB, THUMB_CLOSED)
}

// Open hand: thumb out of the way first, then the fingers
function paper() {
    move(THUMB, THUMB_OPEN)
    basic.pause(MOVE_MS + 200)
    move(INDEX, FINGER_OPEN)
    move(MIDDLE, FINGER_OPEN)
    move(RING, FINGER_OPEN)
    move(LITTLE, FINGER_OPEN)
}

// Scissors: from a fist, raise only the index and middle fingers
function scissors() {
    move(INDEX, FINGER_OPEN)
    move(MIDDLE, FINGER_OPEN)
}

StartbitV2.startbit_Init()
rock()
basic.showIcon(IconNames.Happy)

input.onButtonPressed(Button.A, function () {
    if (playing) {
        return
    }
    playing = true

    // Start every round from a fist, like a real game
    rock()
    basic.showNumber(3)
    basic.pause(500)
    basic.showNumber(2)
    basic.pause(500)
    basic.showNumber(1)
    basic.pause(500)

    const pick = randint(0, 2)
    if (pick == 0) {
        // Rock: already a fist
        basic.showIcon(IconNames.SmallSquare)
    } else if (pick == 1) {
        paper()
        basic.showIcon(IconNames.Square)
    } else {
        scissors()
        basic.showIcon(IconNames.Scissors)
    }

    playing = false
})

Part 7

Clap to grab

Clap once and the hand closes into a fist. Clap again and it opens. The micro:bit V2's built-in microphone listens for loud sounds. After each move it ignores sounds for one second, so the motors' own whirring doesn't count as a clap.

ControlWhat it does
ClapCloses the hand if it's open, opens it if it's closed
Button ALess sensitive, so it needs a louder clap. Shows the new level (up to 9).
Button BMore sensitive, so a quieter clap works. Shows the new level (down to 1).
LED gridBig square = open, small square = fist

New ideas in this program: sound events and tuning. input.onSound(DetectedSound.Loud, ...) runs code whenever the microphone hears something louder than the threshold. setSoundThreshold sets that threshold on the micro:bit's 0–255 scale, and the level buttons move it between 80 and 240. closed = !closed flips between fist and open on each clap.

The program

This is clap-to-grab/main.ts.

// uHandbit clap to grab (micro:bit V2 + StartbitV2 extension)
// Clap once: the hand closes into a fist. Clap again: it opens.
// Button A: less sensitive (needs a louder clap).
// Button B: more sensitive (a quieter clap works).
// Angles confirmed on this hand:
//   fingers (servos 3-6): 0 = closed, 130 = open
//   thumb (servo 2):    140 = closed,   0 = open
// The servos only move with the 6V adapter plugged into the barrel jack.

const FINGER_CLOSED = 0
const FINGER_OPEN = 130
const THUMB_CLOSED = 140
const THUMB_OPEN = 0
const MOVE_MS = 400

// Ignore sounds for this long after a move, so the motors' own noise
// doesn't count as a clap
const QUIET_MS = 1000

// Sensitivity level 1 (quiet claps work) to 9 (needs a very loud clap)
let level = 5
let closed = false
let busy = false

function thresholdFor(lvl: number) {
    // Level 1 = 80, level 9 = 240 on the micro:bit's 0-255 sound scale
    return 60 + lvl * 20
}

function move(servo: number, angle: number) {
    StartbitV2.setPwmServo(StartbitV2.startbit_servorange.range1, servo, angle, MOVE_MS)
}

// Fist: fingers first, then the thumb over them
function makeFist() {
    for (let servo = 3; servo <= 6; servo++) {
        move(servo, FINGER_CLOSED)
    }
    basic.pause(MOVE_MS + 200)
    move(2, THUMB_CLOSED)
    basic.showIcon(IconNames.SmallSquare)
}

// Open: thumb out of the way first, then the fingers
function openHand() {
    move(2, THUMB_OPEN)
    basic.pause(MOVE_MS + 200)
    for (let servo = 3; servo <= 6; servo++) {
        move(servo, FINGER_OPEN)
    }
    basic.showIcon(IconNames.Square)
}

function showLevel() {
    basic.showNumber(level)
    basic.pause(300)
    basic.showIcon(closed ? IconNames.SmallSquare : IconNames.Square)
}

StartbitV2.startbit_Init()
input.setSoundThreshold(SoundThreshold.Loud, thresholdFor(level))
openHand()

input.onSound(DetectedSound.Loud, function () {
    if (busy) {
        return
    }
    busy = true
    if (closed) {
        openHand()
    } else {
        makeFist()
    }
    closed = !closed
    basic.pause(QUIET_MS)
    busy = false
})

input.onButtonPressed(Button.A, function () {
    if (level < 9) {
        level += 1
    }
    input.setSoundThreshold(SoundThreshold.Loud, thresholdFor(level))
    showLevel()
})

input.onButtonPressed(Button.B, function () {
    if (level > 1) {
        level -= 1
    }
    input.setSoundThreshold(SoundThreshold.Loud, thresholdFor(level))
    showLevel()
})

The glowing ultrasonic sensor

Correction: only socket 4 is I2CAn earlier version of this page said sockets 4, 5 and 6 were all I2C and recommended socket 5. That was wrong. Use socket 4 for I2C sensors, and never plug a sensor into socket 6.

Hiwonder's glowing ultrasonic sensor measures distance like the plain one, but it talks to the micro:bit over the I2C bus and has a colored light in each eye. Hiwonder makes it in two shapes. Both work the same way.

Lit eyes need a program. In these photos a program has set the eye colors. Your sensor may stay dark until the micro:bit tells it which color to show. That only works once the micro:bit can talk to the sensor, so dark eyes on their own don't prove the sensor has no power. The I2C scan below is the reliable check.

  1. Power everything off.Unplug USB, switch the board off, unplug the 6V adapter.
  2. Plug the cable into the sensor's white socket.It's keyed, so it fits one way only. Never force it.

Option A: the ESP32 drives the servos directly

Research notes, not a working setupNothing in this part has been tried on the hand. Two things are still unknown: which messages the board accepts on its serial ports, and whether their signals are 5V (which would damage the ESP32). Don't wire anything until those are checked.

The micro:bit doesn't drive the servos itself. It sends short serial messages to a helper chip on the expansion board, and the helper chip moves the servos using the board's 6V power. An ESP32 could send the same messages and take the micro:bit's place, with only 2 or 3 wires.

What's known

FactSource
The micro:bit talks to the helper chip at 115200 baud, sending on pin P12 and listening on P8StartbitV2 extension code
Move a servo: 55 55 08 03 01 timeL timeH servo posL posH, position 500–2500 for 0–180°StartbitV2 extension code
The helper chip replies with text like A……$, including the battery voltageStartbitV2 extension code
Socket 5 is the helper chip's second serial port (5V, GND, RX2, TX2), meant "for a Wi-Fi module"Hiwonder board schematic and notes
The "NC TX RX GND" socket next to socket 2 isn't documented anywhereHiwonder docs and product pages
The uHandbit's phone app uses the micro:bit's own Bluetooth, not these socketsHiwonder lessons and product images

What's unknown

  1. Signal voltage.If the helper chip's TX sends 5V, it can damage the ESP32, whose pins take 3.3V at most.
  2. What socket 5 accepts.It's documented for a Wi-Fi module. Whether the helper chip acts on servo messages arriving there, or only passes them on to the micro:bit, isn't documented.
  3. Where the "NC TX RX GND" socket goes.It might share the micro:bit's line, which would mean removing the micro:bit so the two don't talk at once.

Safe test plan

You'll need jumper wires, plus a multimeter or two resistors (10 kΩ and 20 kΩ).

  1. Measure first.With the board on, measure the socket's TX pin against GND with a multimeter. About 3.3V is safe for the ESP32. About 5V needs the resistors.
  2. Or protect the input anyway.Wire the board's TX through 10 kΩ to ESP32 GPIO 16 (RX2), with 20 kΩ from GPIO 16 to GND. That turns 5V into a safe 3.3V.
  3. Listen only.Connect GND to GND and the board's TX to the ESP32's RX2, nothing else. Upload esp32-lsc-test and watch its USB output. Battery reports mean you've reached the helper chip.
  4. Then send one command.Remove the micro:bit, add ESP32 GPIO 17 (TX2) to the board's RX, and press the ESP32's BOOT button. The index finger should toggle between open and closed.
  5. Never connect power pins.The ESP32 stays on its own USB power. Only GND, TX and RX are connected, and never socket 6.

The test program

This is esp32-lsc-test/esp32-lsc-test.ino. It compiles, but hasn't run on the board yet.

// ESP32 DevKit V1: talk to the uHandbit board's servo controller directly (option A test).
//
// Step 1 (listen only): prints any messages the board's helper chip sends, such as its
//   battery report "A<p14><sound><volt>$", to the Mac over USB.
// Step 2 (only when you press the BOOT button): sends one servo command that toggles
//   the index finger (servo 3) between open (130) and closed (0).
//
// Uses the ESP32's second serial port: RX2 = GPIO 16, TX2 = GPIO 17, 115200 baud.
// Only connect these after the board's serial socket has been verified.

const int RX2_PIN = 16;
const int TX2_PIN = 17;
const int BOOT_BUTTON = 0;
const int LED_PIN = 2;

bool fingerClosed = false;
String incoming = "";

// Hiwonder servo controller frame: 55 55 08 03 01 timeL timeH id posL posH
// Position 500-2500 covers 0-180 degrees, the same as the micro:bit's StartbitV2 extension.
void moveServo(uint8_t id, int angle, uint16_t ms) {
  angle = constrain(angle, 0, 180);
  uint16_t pos = 500 + (uint32_t)angle * 2000 / 180;
  uint8_t frame[10] = {0x55, 0x55, 0x08, 0x03, 0x01,
                       (uint8_t)(ms & 0xff), (uint8_t)(ms >> 8),
                       id, (uint8_t)(pos & 0xff), (uint8_t)(pos >> 8)};
  Serial2.write(frame, sizeof(frame));
  Serial.printf("sent servo %d -> %d degrees (pos %d)\n", id, angle, pos);
}

// "A" frames carry three 2-digit hex values; the last is battery voltage in units of 78.63 mV
void reportFrame(const String &frame) {
  Serial.print("from board: ");
  Serial.println(frame);
  if (frame.length() == 7 && frame.charAt(0) == 'A') {
    long volt = strtol(frame.substring(5, 7).c_str(), nullptr, 16);
    Serial.printf("  battery about %.2f V\n", volt * 78.63 / 1000.0);
  }
}

void setup() {
  Serial.begin(115200);
  Serial2.begin(115200, SERIAL_8N1, RX2_PIN, TX2_PIN);
  pinMode(BOOT_BUTTON, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
  Serial.println("listening to the board; press BOOT to toggle the index finger");
}

void loop() {
  while (Serial2.available()) {
    char c = (char)Serial2.read();
    digitalWrite(LED_PIN, !digitalRead(LED_PIN));  // blink on every byte received
    if (c == '$') {
      reportFrame(incoming);
      incoming = "";
    } else if (incoming.length() < 40) {
      incoming += c;
    }
  }

  if (digitalRead(BOOT_BUTTON) == LOW) {
    fingerClosed = !fingerClosed;
    moveServo(3, fingerClosed ? 0 : 130, 500);
    delay(400);  // ignore the rest of this press
    while (digitalRead(BOOT_BUTTON) == LOW) {
      delay(10);
    }
  }
}

Option B: the ESP32 makes the servo signals itself

Research notes, not a working setupNothing in this part has been tried on the hand. It means unplugging the servos from the Hiwonder board and wiring your own power, which is where mistakes cost parts. Read all of it before connecting anything.

A servo is told where to go by a pulse every 20 ms: 0.5 ms means 0°, 2.5 ms means 180°. The ESP32 can make those pulses on six of its pins at once, so it can drive the hand with no micro:bit and no Hiwonder board. The catch is power: the ESP32 can't supply it, so the servos need their own.

Option A or option B?

Option A (Part 10)Option B (this part)

Wires to the ESP322–37 (six signals + ground)

What you need

  1. A 6V supply rated 5 A or more.Each servo can draw one to two amps when it strains. The kit's 6V 5A adapter is the right size, with a barrel-jack-to-screw-terminal adapter so you can connect wires to it.
  2. A way to connect six servo plugs.A breadboard with pin headers, or a servo breakout board. Each servo plug has three wires: brown (ground), red (power), orange (signal).
  3. Jumper wires from the six signal lines and ground to the ESP32.
  4. A large capacitor (recommended).About 1000 µF, 16V or more, across the servo supply. It smooths the power when several servos start at once. Mind its polarity: the stripe side goes to GND.

Wiring

WireGoes to
Every servo's red (power)Supply +6V. Never an ESP32 pin, not even VIN or 5V.

Pins chosen on purpose. GPIO 13, 14, 25, 26, 27 and 33 are plain outputs. Avoid GPIO 0, 2, 12 and 15 (they affect how the ESP32 starts), 6–11 (its memory chip), 1 and 3 (the USB link), and 34–39 (inputs only). The ESP32 still runs from its own USB power.

Unverified: 3.3V signals. The ESP32's signal pins give 3.3V. Most hobby servos accept that, but the LD-1501MG's minimum isn't documented. If a servo jitters or ignores commands, add a small logic-level shifter between the ESP32 and the signal wires.

Easier variant: a servo driver board

A PCA9685 16-channel servo board (a few dollars) takes most of the wiring off your hands. The servo plugs fit its three-pin headers directly, the 6V supply goes into its screw terminal, and the ESP32 connects with four wires: 3.3V, GND, SDA (GPIO 21) and SCL (GPIO 22). The board makes the pulses itself. It needs the Adafruit PWM Servo Driver library and a small change to the program.

Safe test plan

  1. One servo first.Wire only the index finger (servo 3) and the grounds. Power the ESP32 by USB, then switch on the 6V supply.
  2. Expect a jump at power-on.When the signal starts, each servo goes straight to its start position: hand open, wrist at 90°. Keep your fingers clear.
  3. Use the sliders gently.Join uHandbit-Direct, open 192.168.4.1, and move the index slider. The program moves at about 150° per second so nothing snaps.
  4. Feel for heat, listen for buzzing.A servo that buzzes or warms up at rest is pushing against a stop. Switch off and adjust the angle limits.
  5. Then add the other five.One at a time, checking each before the next.

The program

This is esp32-direct-servos/esp32-direct-servos.ino, shown without the long control-page text it shares with the Bluetooth remote. It compiles, but hasn't run on the hand yet.

// uHandbit option B: the ESP32 drives the six servos directly (no micro:bit, no Hiwonder board).
// NOT TESTED ON THE HAND YET. Read the wiring notes on the guide page before connecting anything.
//
// The ESP32 makes its own Wi-Fi network. Join it from your phone and open http://192.168.4.1
// The page is the same as the Bluetooth remote, but here the ESP32 moves the servos itself.
//
// Wiring (servo cable colors):
//   brown (ground) -> servo power supply GND, and ESP32 GND
//   red (power)    -> servo power supply +6V   (NEVER the ESP32's pins)
//   orange (signal)-> ESP32 pin from SERVO_PINS below

#include <WiFi.h>
#include <WebServer.h>

const char *AP_NAME = "uHandbit-Direct";
const char *AP_PASSWORD = "handbit123";

// Servo 1 wrist, 2 thumb, 3 index, 4 middle, 5 ring, 6 little.
// These pins are safe general-purpose outputs on the DevKit V1 (no boot or flash pins).
const int SERVO_PINS[7] = {-1, 13, 14, 27, 26, 25, 33};

// Angles confirmed on this hand: fingers 0 = closed, 130 = open; thumb 140 = closed, 0 = open
const int FINGER_CLOSED = 0, FINGER_OPEN = 130, THUMB_CLOSED = 140, THUMB_OPEN = 0;
const int COUNT_SERVOS[5] = {3, 4, 5, 6, 2};
const int COUNT_OPEN[5] = {130, 130, 130, 130, 0};
const int COUNT_CLOSED[5] = {0, 0, 0, 0, 140};

// Start positions: open hand, wrist in the middle
float current[7] = {0, 90, THUMB_OPEN, FINGER_OPEN, FINGER_OPEN, FINGER_OPEN, FINGER_OPEN};
int target[7] = {0, 90, THUMB_OPEN, FINGER_OPEN, FINGER_OPEN, FINGER_OPEN, FINGER_OPEN};
const float STEP_DEGREES = 3.0;  // per 20 ms, about 150 degrees per second, so moves aren't violent

bool waving = false;
unsigned long lastStep = 0, lastWave = 0;
bool waveLeft = false;

WebServer server(80);

// 50 Hz servo signal with 14-bit resolution: 20 ms period = 16384 steps
void writeServo(int servo, float angle) {
  int us = 500 + (int)(constrain(angle, 0, 180) * 2000 / 180);  // same 500-2500 us range as Hiwonder
  ledcWrite(SERVO_PINS[servo], (uint32_t)us * 16384 / 20000);
}

void setTarget(int servo, int angle) {
  if (servo >= 1 && servo <= 6) {
    target[servo] = constrain(angle, 0, 180);
  }
}

bool handle(const String &line) {
  char cmd = line.charAt(0);
  if (cmd == 'F') {
    waving = false;
    for (int s = 3; s <= 6; s++) setTarget(s, FINGER_CLOSED);
    setTarget(2, THUMB_CLOSED);
  } else if (cmd == 'O') {
    waving = false;
    setTarget(2, THUMB_OPEN);
    for (int s = 3; s <= 6; s++) setTarget(s, FINGER_OPEN);
  } else if (cmd == 'W') {
    waving = true;
  } else if (cmd == 'X') {
    waving = false;
  } else if (cmd == 'C') {
    waving = false;
    int n = constrain(line.substring(2).toInt(), 0, 5);
    for (int i = 0; i < 5; i++) setTarget(COUNT_SERVOS[i], i < n ? COUNT_OPEN[i] : COUNT_CLOSED[i]);
  } else if (cmd == 'S') {
    int space = line.indexOf(' ', 2);
    if (space < 0) return false;
    int servo = line.substring(2, space).toInt();
    if (servo == 1) waving = false;
    setTarget(servo, line.substring(space + 1).toInt());
  } else {
    return false;
  }
  return true;
}

const char PAGE[] PROGMEM = R"HTML(... the same phone page as esp32-hand-remote ...)HTML";

void handleRoot() {
  server.send_P(200, "text/html", PAGE);
}

void handleCmd() {
  String c = server.arg("c");
  if (c.length() == 0 || c.length() > 12) {
    server.send(400, "text/plain", "bad command");
    return;
  }
  server.send(200, "text/plain", handle(c) ? "ok" : "bad command");
}

void handleStatus() {
  server.send(200, "application/json", "{\"connected\":true,\"name\":\"direct servos (ESP32)\"}");
}

void setup() {
  Serial.begin(115200);
  for (int s = 1; s <= 6; s++) {
    ledcAttach(SERVO_PINS[s], 50, 14);
    writeServo(s, current[s]);
  }
  WiFi.softAP(AP_NAME, AP_PASSWORD);
  Serial.print("Wi-Fi network ");
  Serial.print(AP_NAME);
  Serial.print(" ready. Open http://");
  Serial.println(WiFi.softAPIP());
  server.on("/", handleRoot);
  server.on("/cmd", handleCmd);
  server.on("/status", handleStatus);
  server.begin();
}

void loop() {
  server.handleClient();
  unsigned long now = millis();

  // Wrist wave: swing between 0 and 180 every second
  if (waving && now - lastWave > 1000) {
    waveLeft = !waveLeft;
    target[1] = waveLeft ? 0 : 180;
    lastWave = now;
  }

  // Move every servo a small step toward its target every 20 ms
  if (now - lastStep >= 20) {
    lastStep = now;
    for (int s = 1; s <= 6; s++) {
      float diff = target[s] - current[s];
      if (diff != 0) {
        current[s] += constrain(diff, -STEP_DEGREES, STEP_DEGREES);
        writeServo(s, current[s]);
      }
    }
  }
}
